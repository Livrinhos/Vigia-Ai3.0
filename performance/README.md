# VigiaAI Performance

Esta pasta contém o código completo da versão Performance, usado também como base do VigiaAI 3.0.
Não é necessário selecionar ou extrair outro ZIP.

Na raiz do projeto, execute **Instalar.cmd** uma vez. Depois use **Iniciar-Performance.cmd**
para esta versão ou **Iniciar-VigiaAI3.cmd** para a versão com Banco de Imagens e Treinamento.

Os modelos originais são preparados automaticamente pelo instalador e verificados por SHA-256.
Pesos existentes não são substituídos. Fotos, datasets e modelos novos permanecem fora do GitHub.
